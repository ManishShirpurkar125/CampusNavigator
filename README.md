# Campus Navigator — Homepage

A responsive college-discovery homepage built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and college cards
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation, live college search and image fallback

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted `Campus-Navigator` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the Live Server extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Working features
- Responsive navigation menu for mobile screens.
- Search filters college names, types and locations as you type.
- Each college card links to its official website and a Google Maps search.
- Image fallback appears if a remote photo cannot load.

## College photo note
The college cards use externally hosted photographs found through public web image results. They are not stored inside this ZIP, so an internet connection is needed. Please check each image's usage rights and replace it with a college-approved image if required for public or commercial publishing. The images are intended to depict the named institutions, but image hosting and availability can change.

## Scope
This is a functional homepage prototype. It does not yet implement live campus maps, building-level indoor navigation, accounts or a backend.


## Login page
- Open `login.html` from the project folder or click **Login** on the homepage.
- The form checks email format and requires at least 6 password characters.
- The show/hide password control works.
- This is a front-end demonstration only. It does not authenticate users, create accounts, or store/send passwords. A secure backend and authentication service are required for real login.


## Project logo
The supplied Campus Navigator logo is saved locally at `images/campus-navigator-logo.png` and appears in the homepage header, footer, and login page. Keep the `images` folder in the same project folder so the logo loads correctly.
